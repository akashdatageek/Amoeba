# Income Data Tables

The tables below provide income statistics displayed in tables with columns and rows. Many tables are in downloadable in XLS, CVS and PDF file formats. If you are using a screen reader and are having problems accessing data, please call 301-763-3243 for assistance.

To filter data tables for a specific survey use the links below:

* [Current Population Survey (CPS)](/topics/income-poverty/income/data/tables/cps.html)
* [American Community Survey (ACS)](/topics/income-poverty/income/data/tables/acs.html)
* [Survey of Income and Program Participation (SIPP)](/topics/income-poverty/income/data/tables/sipp.html)
* [Decennial Census](/topics/income-poverty/income/data/tables/dec.html)
