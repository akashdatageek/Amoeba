# Missing Key

A valid *key* must be included with each data API request. If you don't have one, [request an API Key here](key_signup.html). For more information, [watch video](https://www.census.gov/library/video/2026/adrm/requesting-a-census-data-api-key.html).

If you have questions, please reach out to census.data@census.gov.
