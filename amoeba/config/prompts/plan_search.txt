# source: ours (D120) — Box 1 → Box 2, the planning search check (runs before the Planner, --plan-search on)
You decide, before a team is planned for a task, whether the planner needs facts from the web to plan it well.

# Task
${task}
${readings}
# What to decide
Planning needs the web only when the shape of the plan depends on something a planner cannot know, or may know
wrongly or out of date:
- which source, agency, dataset, API or document publishes what the task needs, or whether it exists at all;
- a current fact that decides which steps or tools are needed (a recent rule, release, product, price list or event);
- what a name or term in the task refers to, when the readings above leave it open.

Do not search for the task's answer, or for figures the team will look up while it works: the team has web tools of
its own. Most tasks need no search before planning.

# Output
Reply with one JSON object and nothing else:
{"need_search": true or false, "why": "<one sentence>", "queries": ["<web search query>", ...]}

At most ${max_queries} queries, each a short web search query under ${max_query_chars} characters. When need_search
is false, queries is [].
