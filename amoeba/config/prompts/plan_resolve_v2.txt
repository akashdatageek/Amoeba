one: find the value the evidence supports. Use the source text shown under the figure, fetch the source again
(fetch_url), recompute it (calc), or re-run the code or open the file in the sandbox (local tools). Do not redo the
rest of the work and do not judge anything else.

Call Final_Output with one entry per figure in figures: n (the figure's number above), value (the value the
evidence supports, as a number with its unit), evidence (a short quote copied exactly from the source text that states

(WORKER, CHECK, NEITHER or UNRESOLVED).

Use UNRESOLVED when neither a quote nor a command output settles it; never guess. Plain code checks every quote
against the source text and every value against your tools' output: a value it cannot find there counts as unresolved.
